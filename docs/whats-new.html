MYNT 3.5.0 — AI Assist

Reese-max 客製版 · 本機優先 AI 輔助 · 上游融合基準 e279bb9

AI Assist 第一階段

  • Today 新增「AI 幫我安排今天」，依待辦、Top 3、釘選任務、今日目標與近期專注紀錄提出建議。
  • Scratchpad 新增「AI 整理」，可產生摘要、擷取待辦、整理 Markdown，並由使用者決定是否加入 Todo 或取代便箋。
  • 提供 Auto、Chrome 內建 AI、Local smart assist、Off 四種模式。
  • Auto 模式會優先使用 Chrome Prompt API；不可用時自動退回本機固定規則，因此 Firefox、舊 Chrome 與未下載模型的裝置仍可使用。
  • 第一階段沒有 MYNT 雲端 AI endpoint、沒有 API Key，也不會自動把 Todo 或 Scratchpad 傳送到遠端伺服器。

仍保留的 3.4.0 融合成果

  • 上游融合基準仍為 e279bb9，保留自訂捷徑圖示、Daily Quote、Alt + 1 至 Alt + 9、32 種語言與主題／桌布修正。
  • Today Top 3、下一步行動、專注統計、Workspaces、Scratchpad、Search Bang 與 Command Palette。
  • Pomodoro 任務連動、環境音、備份還原、隱私中心與無障礙控制。
