# MYNT 美感升級設計簡報（award-ui）

## 目標

以 Awwwards Site of the Day 的評分方式為品質標準（設計 40%、易用性 30%、創意 20%、內容 10%），並參考 Webby 的「結構與導覽、互動性、整體體驗」與 FWA 的「創新」。
達標條件：兩位不同模型家族的評審，都給出加權總分 ≥ 8.0，且任一項不低於 7.5。評分細則見 `docs/design/rubric.md`。

## 產品脈絡

- MYNT 是 Chrome／Firefox 的新分頁擴充功能，使用者每天會開幾十次。
- 繁體中文優先、本機優先（資料都存在瀏覽器本機），資訊密度高：搜尋、捷徑、待辦、番茄鐘、便籤、工作區、天氣。
- 有 11 種主題色（`--bg-color-blue` 等）、深淺色模式、使用者自訂桌布與自適應取色。
- 2026-09 產品稽核的定位：要比 Momentum、Tabliss、Bonjourr 更好用，**不要為了極簡把工作流功能藏起來**。

## 不能動的東西（任何一項違反，該輪直接作廢）

1. 功能與行為：不刪功能、不改互動流程、不改 JavaScript。
2. 資料：不改任何 localStorage／chrome.storage 鍵名與格式。
3. 權限與資源：不新增權限、不加外部字型／CDN／網路請求、不加圖片素材。
4. 速度：新分頁開啟不能比基準慢超過 10%；避免大面積 `backdrop-filter`、大量陰影疊加、會持續觸發重繪的動畫。
5. 可用性：鍵盤可操作、焦點框清楚可見、文字對比至少 WCAG AA（一般文字 4.5:1，大字 3:1）。
6. 主題：11 種主題色 × 深淺色都要好看；使用者自訂桌布時文字仍可讀。
7. 動效：一律尊重 `prefers-reduced-motion: reduce`。

## 實作規則

- 只新增 `styles/award-theme.css`，並在 `index.html` 最後一個 stylesheet `<link>` 之後加一行載入它。其他檔案不要改。
- 純 CSS。優先改設計 token（`:root` 與各主題的 CSS 變數），再處理個別元件。
- 盡量不用 `!important`；非用不可時，選擇器要具體，並在旁邊註解原因。
- 字型只用本機已有的：Poppins（拉丁字）＋系統中文字型。建議字型堆疊：
  `"Poppins", "Microsoft JhengHei UI", "Microsoft JhengHei", "PingFang TC", "Noto Sans TC", sans-serif`
- 註解用繁體中文，簡短說明每個區塊的設計意圖。

## 三個候選方向（P0 只做其中一個，由派工指定）

### A：精緻 Material 3 Expressive
沿用 Material You 的語言，但做到教科書等級的精緻：明確的字級階層（display／title／body／label）、4／8px 間距節奏、色調層次分明的 surface（surface-container 階層）、一致的圓角家族與 elevation、帶彈性但克制的動效。

### B：沉靜編輯排版
像一本設計精良的雜誌：較大的字級對比與行高、寬鬆留白、降低飽和度的中性色、細線分隔取代厚重卡片，讓資訊密度高卻不擁擠。主題色只用在重點與互動狀態。

### C：光影層次
利用桌布與主題色營造深度：分層的半透明面板（只在少數大面板用 `backdrop-filter`，並提供不支援時的退路）、柔和的光暈強調主題色、清楚的前後景關係。必須守住速度與對比。
