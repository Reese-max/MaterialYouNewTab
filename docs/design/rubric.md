# MYNT 美感評分表（award-ui）

評審依固定截圖逐項打分，每項 1–10 分，可給小數一位。每個扣分都要寫出看得到的具體理由（哪張圖、哪個位置、什麼問題）。

## 維度與權重

| 維度 | 權重 | 檢查項 |
|---|---|---|
| 設計 design | 40% | 字級階層清楚；間距節奏一致；色彩與對比（含 11 種主題色、深淺色）；圓角、陰影、邊框風格一致；對齊；圖示風格一致；中英混排的字型協調 |
| 易用性 usability | 30% | 一眼找到搜尋／待辦／專注；資訊層級與導覽（Webby「結構與導覽」）；可點範圍與狀態回饋（hover、focus、active、disabled）；焦點框；空狀態；對話框與面板的清楚程度 |
| 創意 creativity | 20% | 讓人記得住的細節與個性（FWA「創新」）；微互動與層次（Webby「互動性」）；主題色與桌布的運用；不落入「AI 生成網頁」的套版感 |
| 內容 content | 10% | 繁中用字、語氣、標點；提示文字清楚；資訊密度恰當 |

加權總分 = 0.4 × design + 0.3 × usability + 0.2 × creativity + 0.1 × content。

## 分數定錨

| 分數 | 意義 |
|---|---|
| 5 | 能用但普通，看得出是範本或預設樣式 |
| 6 | 整齊，但缺乏層次或有明顯不一致 |
| 7 | 有設計感，少數細節不一致 |
| 8 | 精緻、一致、有個性，可以拿去當作品集 |
| 9 | 獎項等級，細節經得起放大檢查 |
| 10 | 業界標竿 |

## 達標條件

兩位不同家族的評審都給：加權 ≥ 8.0，且每一項 ≥ 7.5。

## 評審輸出格式（JSON）

```json
{
  "scores": { "design": 0, "usability": 0, "creativity": 0, "content": 0 },
  "weighted": 0,
  "deductions": [
    { "dimension": "design", "shot": "<檔名>", "where": "<位置>", "issue": "<問題>", "fix": "<建議改法>", "severity": "high|medium|low" }
  ],
  "top_fix": "<下一輪最值得改的一件事>"
}
```

## 截圖矩陣

狀態 × 主題 × 視窗寬度：
- 狀態：`home`（預設首頁）、`menu`（設定選單）、`todo`（待辦清單）、`pomodoro`（番茄鐘）、`layout`（版面編輯）、`dialog`（確認對話框）
- 主題：`light`、`dark`
- 寬度：`1920x1080`、`1366x768`

## 機器閘門（任一項沒過，該輪作廢）

- 既有 QA 14 項、Chromium 煙霧測試通過
- 每張截圖的 console 錯誤為 0
- 文字對比不低於 WCAG AA
- 新分頁開啟時間不比基準慢超過 10%
- 沒有新增權限、外部資源或網路請求
- localStorage 鍵名不變
