WeatherAPI 金鑰取得指南

步驟 1：前往 WeatherAPI 網站

前往 WeatherAPI 官方網站：https://www.weatherapi.com/。

步驟 2：註冊帳戶

  1. 點擊首頁右上角的 Sign Up（註冊）按鈕。
  2. 填寫必要欄位：
    • 電子郵件地址：提供一個有效的電子郵件地址。
    • 密碼：建立一個安全的密碼。
  3. 同意服務條款。
  4. 如有提示，請完成 CAPTCHA 驗證。
  5. 點擊 Sign Up 建立您的帳戶。

注意：如果您已有帳戶，請點擊 Login（登入）並輸入您的帳號密碼。

步驟 3：驗證您的電子郵件地址

請檢查您的電子郵件收件匣，查看 WeatherAPI 寄來的驗證郵件。開啟郵件並點擊其中提供的驗證連結。

提示：如果在收件匣中找不到郵件，請檢查垃圾郵件或垃圾桶資料夾。

步驟 4：登入您的帳戶

  1. 返回 WeatherAPI 網站。
  2. 點擊 Login（登入）。
  3. 輸入您的電子郵件地址和密碼。
  4. 點擊 Login 存取您的帳戶。

步驟 5：複製您的 API 金鑰

  1. 登入後，前往 Dashboard（儀表板）。
  2. 如果 API 區段未開啟，請找到並開啟它。
  3. 您會看到您的 API 金鑰以及 Copy（複製）選項。點擊它即可複製您的 API 金鑰。

步驟 6：貼上您的 API 金鑰

  1. 將您的 API 金鑰貼到擴充功能選單中的 WeatherAPI 金鑰欄位。
  2. 按下 Enter 或點擊儲存按鈕以完成設定。

常見問題

為什麼位置不準確？

此擴充功能使用您的 IP 位址來判斷位置，這通常不太精確。如果偵測到的位置與您的實際位置不同，您可以：

  • 手動輸入您的城市名稱或地理座標。
  • 使用 GPS 選項取得更精確的位置。

為什麼需要 API 金鑰？

API 金鑰是用於管理存取權限和監控使用量的唯一識別碼。

  • 我們的擴充功能目前使用共享的 API 金鑰，每月允許最多 15,000,000 次呼叫。由於超過 300,000 位活躍使用者，這些共享金鑰可能很快就會達到上限。一旦達到上限，天氣資料將無法存取，直到下個月限額重設。
  • 使用您自己的 API 金鑰可確保天氣資料始終可用。

使用自己的 API 金鑰有什麼好處？

使用您自己的 API 金鑰有以下幾個主要優勢：

  • 不中斷服務：使用自己的 API 金鑰可避免意外的限額問題，確保服務不中斷，讓您持續存取天氣資料。
  • 位置建議：在位置輸入欄位中啟用位置搜尋建議，讓您在輸入時快速找到並選擇正確的位置選項。
  • 分析報告：透過帳戶儀表板的詳細報告，存取 API 使用情況的深入分析。
  • 隱私保護：您的 API 活動僅與您的帳戶關聯，確保資料保持私密且受到保護。
  • 合規性：確保遵守 WeatherAPI 的服務條款和使用政策，避免違規。
