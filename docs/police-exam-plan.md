# MYNT × 警察特考三等資訊管理組：備考功能規劃

> 目標：把每天打開的新分頁變成「備考儀表板」，讀書時間、題目練習、複習都從新分頁開始做。
> 狀態：只是規劃，還沒有實作。工時預估以 1 人日 ≈ 6 小時計算。

## 現有基礎（直接沿用）

| 既有功能 | 備考用途 |
|---|---|
| Pomodoro 番茄鐘 + 專注統計 | 計時單位、每日讀書時數 |
| Workspaces 工作區 | 「讀書模式」preset：控制小工具、背景、專注分鐘數 |
| Todo / Tasks | 每日讀書清單 |
| Habits 習慣 | 每日打卡（寫題、背法條、英文單字） |
| Scratchpad (Alt+S) | 臨時筆記、錯題草稿 |
| Command Palette (Ctrl+K) | 所有新功能的快速入口 |
| Search bangs (!yt、!gh…) | 新增考古題搜尋 bang |
| Bookmarks | 法規、題庫、課程連結 |
| 桌布圖庫 (Alt+W) | 讀書／休息時切換不同背景 |

## 可整合的自有資源

- **Reese-max/police-exam-practice**：考古題線上練習（110–114 年三等：國文、憲法與英文、警察法規、情境實務）
- **Reese-max/exam-archive**：資管組考古題（105–114 年）

整合原則：以本機 JSON 題庫優先，不要每次開新分頁都抓遠端資料。如果需要更新，用 build 腳本從 repo 匯出 `data/questions.json` 打包進擴充功能（符合 MV3 CSP、不載入遠端程式碼）。

## P0：先做，馬上有效（合計約 4–5 人日）

| 功能 | 說明 | 工時 |
|---|---|---|
| 考試倒數 | 小工具顯示「距離考試 N 天」，可設定考試日期與目標，Command Palette 加「設定考試日期」 | 0.5 天 |
| 每日一題 widget | 從 police-exam-practice／exam-archive 匯出的題庫每天抽 1 題（依日期 seed 固定）；可作答、顯示解答與出處年份科目 | 1.5 天 |
| 考古題 bang | `!考古 關鍵字` / `!kg` 搜尋 exam-archive；`!練習` 開啟練習網站；也加進 Bookmarks 預設分組 | 0.5 天 |
| 讀書工作區 preset | 一鍵啟用：番茄鐘 50/10、Todo、每日一題、倒數，背景改成靜態桌布，隱藏娛樂捷徑 | 0.5 天 |
| 每日目標 | 設定每日讀書分鐘數／題數，新分頁顯示進度環，與 Pomodoro 完成次數連動 | 1 天 |

## P1：核心學習循環（合計約 6–8 人日）

| 功能 | 說明 | 工時 |
|---|---|---|
| 科目別讀書時間 | 番茄鐘開始時選科目（資料庫、資通安全、資訊管理、程式設計、國文、憲法英文、警察法規、情境實務），統計每週／每月時數與比例圖 | 2 天 |
| 錯題本 + 間隔複習 | 每日一題或練習答錯時一鍵收入錯題本（IndexedDB）；用 SM-2／Leitner（1、3、7、14、30 天）排程，新分頁顯示「今日待複習 N 題」 | 3 天 |
| 科目進度 | 每科章節清單與完成百分比、考古題年份覆蓋表（105–114 × 科目） | 1.5 天 |
| 法條速記卡 | 警察法規重點條文卡片，加入同一套間隔複習排程 | 1 天 |

## P2：加分項（合計約 5–7 人日）

| 功能 | 說明 | 工時／可行性 |
|---|---|---|
| 專注模式擋網站 | 讀書工作區啟用時，用 `declarativeNetRequest` 動態規則把 YouTube、社群等網站導向「專心讀書」頁面；需要新增權限，只在使用者同意後啟用 | 2 天；可行，但要評估權限與商店審核 |
| 模擬考計時 | 依科目設定考試時間的整卷模擬，結束後統計正確率並把錯題送進錯題本 | 2 天 |
| 每週回顧報告 | 週日自動產生：時數、題數、正確率、最弱科目，並建議下週分配 | 1 天 |
| 備份同步 | 錯題本／進度併入既有 backup-restore 匯出；可選 chrome.storage.sync 同步少量設定 | 1 天 |
| 考試資訊提醒 | 報名、考試、放榜日期（手動輸入或從考選部日程匯入 .ics） | 0.5 天 |

## 建議順序

1. P0 全部做完（大約一週）→ 先每天用一週
2. P1 錯題本 + 科目時間（最能提高分數的循環）
3. 依實際使用情況再挑 P2

## 技術注意事項

- 新增資料一律存 IndexedDB；設定存 localStorage／chrome.storage
- 字串先寫 zh_TW，英文當 fallback，與現有 locale loader 相容
- 新 script 依照現有 `defer` 模式加入，並更新 `tools/check-customizations.mjs`
- 不載入遠端程式碼；題庫用本機 JSON 打包
