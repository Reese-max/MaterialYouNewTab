MYNT: Material You New Tab 隱私權政策

最後更新：2026 年 10 月 24 日

簡介

「MYNT: Material You New Tab」是一款開源擴充功能，旨在美化瀏覽器的預設首頁和新分頁。它最初是使用 HTML、CSS 和 JavaScript 開發的個人專案。由於獲得正面評價，後來在 Firefox 和 Chrome 線上應用程式商店上架。

社群貢獻

自發布以來，社群中優秀的開發者透過 GitHub 為改善此擴充功能做出了貢獻。這些貢獻者新增了新功能並修復了錯誤，使擴充功能更加完善。每個 Pull Request 都經過仔細審查、測試和驗證，確保符合我們的標準後才會合併。

番茄鐘小窗與本機媒體

番茄鐘的 pomodoroState（版本 2）在 localStorage 保存結束時間、暫停狀態、任務與回合。分頁使用本機鎖協調完成提示，沒有新增帳號、網路服務或瀏覽器權限；關閉瀏覽器或休眠不保證準時提醒。小窗僅由按鈕開啟，一般彈出視窗不保證置頂。

myntPomoScenarios、myntPomoStudioMode、myntPomoAlarmVolume 保存情境、介面與提示音偏好。myntPomodoroAppearance.v1 保存獨立背景設定；IndexedDB MyntPomodoroAppearance 的 images 保存一張最多 8 MiB 本機圖片。myntPomodoroMusicV1 的 tracks 保存自選音樂，最多 30 首、每首 100 MiB、合計 300 MiB；myntPomoMusicSettingsV1 保存播放順序、音量與休息政策，myntPomoMusicOwnerV1 僅用於暫時跨分頁播放協調。媒體不會上傳伺服器；第 3 版本機備份可選「設定＋媒體」或「僅設定」（含編碼資料上限 32 MiB），舊版備份不含完整媒體庫；移除擴充功能或清除網站資料可能刪除。情境只保存媒體識別與偏好，不複製音樂檔。

Timer, scenarios, images and music remain browser-local. No media is uploaded. Version 3 local backups offer settings plus media or settings-only exports within a 32 MiB encoded-file limit; older backups do not contain complete media libraries. Browser shutdown, sleep and autoplay restrictions can prevent timely alarms or playback. Floating windows require the original tab; ordinary popup windows are not guaranteed to remain on top.

背景自適應與排版儲存

myntLayoutProfiles（版本 1）只在本機保存命名組合、寬／窄螢幕位置、上一個儲存版本與修訂號。舊 myntLayout 保留，不刪除；排版專用 JSON 匯出不含便籤、帳號或 API 金鑰，匯入先驗證並確認後新增副本。不同分頁的過期寫入會拒絕，以免覆寫更新。

Named layout profiles and previous versions stay in localStorage. Layout-only exports contain no notes, accounts or API keys; validated imports add copies after confirmation.

背景圖片與影片像素只在本機 Canvas 進行低解析度色彩、亮度與紋理分析，不傳送到模型或伺服器。localStorage 的 myntAdaptiveBackground（版本 1）保存配色、對比、透明度開關，舊自動排版設定固定轉為關閉；myntLayout（版本 2）保存手動相對位置、縮放、格線與鎖定。背景功能不會移動元件，也不覆寫手動位置。這些設定不跨裝置同步，清除網站資料會刪除設定。無新增權限、網路服務或遙測。

Adaptive background processing stays on-device. Versioned local preferences are stored in myntAdaptiveBackground and myntLayout. No pixels are uploaded and no new remote service is used.

資料收集與權限

MYNT 不包含由專案營運的分析工具、追蹤腳本、遙測或遠端記錄系統。偏好設定、待辦事項、快取資料與客製內容主要儲存在您的瀏覽器內；但啟用語音辨識、隨機桌布或網站圖示等功能時，瀏覽器會直接連線至下列第三方服務。第三方至少會看到一般網路請求中包含的 IP 位址，並可能收到查詢字詞、位置或網站網域。

權限

我們僅要求提供豐富、動態瀏覽體驗所需的最低權限。以下是所使用權限的說明：

  • 書籤：只在您啟用書籤功能後請求。此權限可讀取、新增、修改與刪除瀏覽器書籤。
  • 網站圖示（Chrome 選用）：用於從瀏覽器快取讀取書籤圖示。若快取沒有圖示，書籤會改用內建替代圖示，不傳送書籤網域。

瀏覽器 API

  • 語音辨識（Web Speech API）：僅在您點擊麥克風圖示後啟動。音訊處理由瀏覽器提供者控制，依瀏覽器實作可能傳送至其語音服務；MYNT 不另行儲存音訊。
  • 地理位置：目前版本已隱藏式移除天氣功能，不要求地理位置權限，也不使用或傳送位置資訊。既有本機天氣設定與快取保留，不會自動清除。 / Weather is removed in this version. MYNT does not request geolocation or use or transmit location information; existing local weather preferences and cache are retained.

外部 API

只有相關功能啟用或觸發時，MYNT 才會使用下列服務：

  • 位置偵測（IPinfo）：

    目前版本不連線 IPinfo，不以 IP 位址查詢位置；即使舊設定曾開啟天氣或 GPS 也不會查詢。 / This version does not contact IPinfo or look up location by IP, even with previously enabled weather or GPS preferences.

  • 天氣更新（WeatherAPI）：

    天氣已於 2026-11-23 依擁有者決定隱藏式移除。目前版本不連線 WeatherAPI，不查詢天氣或城市建議，也不傳送既有位置或自訂金鑰。程式碼、語系與本機儲存值保留，以便日後恢復功能；自訂 WeatherAPI 金鑰仍排除於一般備份，還原時保留目的端金鑰。 / Weather was reversibly removed on 2026-11-23. This version does not contact WeatherAPI for forecasts or city suggestions, or transmit saved locations or API keys. Code, translations and local data remain available for future restoration. Custom WeatherAPI keys remain excluded from ordinary backups and are preserved at the destination during restore.

  • 隨機桌布（Lorem Picsum）：
    • https://picsum.photos/1920/1080 — 用於取得高品質隨機圖片。
  • 網站圖示擷取（Google Favicon API）：
    • https://s2.googleusercontent.com/s2/favicons*
    • https://www.google.com/s2/favicons*
    捷徑預設使用這些服務，服務會收到捷徑的網站網域以擷取圖示。可在「設定 > 捷徑」關閉；關閉後不會為捷徑圖示向 Google 發出請求。書籤改用瀏覽器本機快取或內建替代圖示。

考古題

「今日考古題」預設顯示，啟用時會在閒置後從 raw.githubusercontent.com 的 Reese-max/police-exam-archive 公開題庫下載並快取當日題目。GitHub 會收到一般網路請求資訊（例如 IP），請求不含待辦、便籤或書籤。可在設定停用此卡片，停止後續自動題庫請求。

本機儲存

一般待辦介面的刪除也會在既有 myntTodoRecoveryV1 保留最後一筆項目及原位置。寫入失敗會嘗試回滾；再次刪除會取代同類型的上一筆復原紀錄。復原不需要連接 MCP。

Task deletions in the ordinary UI retain the last item and its original position in myntTodoRecoveryV1. Failed writes attempt rollback. Another UI deletion replaces the preceding recovery item in that list. Undo needs no MCP connection.

MYNT 使用 localStorage 與 IndexedDB 儲存介面設定、待辦事項、書籤顯示偏好、自訂捷徑圖示、天氣位置與快取、番茄鐘狀態、工作區預設、無障礙偏好及上傳的桌布。移除擴充功能或清除網站資料時，瀏覽器可能一併刪除這些內容。

控制中心的服務狀態只會在 localStorage 記錄服務識別名稱、成功或失敗結果、HTTP 狀態碼及時間；不會記錄完整網址、搜尋文字、位置、API 金鑰，也不會傳送至專案營運者。

更新與解除安裝頁面

Chromium 版本更新後會在本機開啟擴充功能內的 docs/whats-new.html，說明本次整合內容。解除安裝後，瀏覽器可能開啟 Reese-max Fork 的公開 GitHub 頁面供您自行查看；此動作不會自動上傳擴充功能設定、便籤、待辦、搜尋文字、位置、API 金鑰或其他本機資料。

透明度與安全性

雖然我們努力保持程式碼的安全性，但我們承認沒有任何專案能完全避免潛在問題。在少數情況下，可能會因貢獻而引入非預期的程式碼或錯誤。我們鼓勵使用者直接在 GitHub 上檢閱原始碼以確保安心。請僅在您完全信任其內容時使用此擴充功能。

感謝

感謝您對 MYNT: Material You New Tab 擴充功能的信任。我們希望它能在您每次開啟新分頁時提升您的瀏覽體驗！

Layout draft recovery uses sessionStorage (myntLayoutDraft) only in the current tab and survives reload, not guaranteed tab closure. The dismissible guide preference uses localStorage (myntLayoutGuideSeen). Deleted layout profiles remain recoverable locally; no data is uploaded.

Deleting a wallpaper you added removes it, after confirmation, from this browser’s local IndexedDB: it cannot be restored and its storage is freed. Built-in wallpapers ship with the extension, so deleting one only removes it from the gallery and the home page; it stays in Recovery and can be restored. Items removed by earlier versions or by local MCP stay in Recovery, still use local storage, and can be restored or deleted permanently there. Original files on your device are not modified or uploaded.

「僅設定」可匯出一般設定、排版、待辦及還原後暫停的計時狀態，不讀取或包含媒體資料庫，也不包含桌布偏好、計時器外觀、音樂偏好與已儲存專注情境。還原時保留目的端的這些媒體及偏好；舊版 v1／v2 備份同樣保留未涵蓋的媒體關聯偏好。完整備份不會自動降級為僅設定；音樂庫可達 300 MiB，不代表能放入 32 MiB 備份，請另行保留原始媒體檔。

Settings-only exports omit media databases and media-linked wallpaper, timer appearance, music and saved scenario preferences. Restoring them preserves those existing destination files and preferences. Legacy v1/v2 restores likewise preserve omitted media-linked preferences. Full exports never silently downgrade; retain original media separately when the 32 MiB encoded backup limit is exceeded.

本機備份第 3 版的「設定＋媒體」包含設定、排版、待辦、圖庫（含回收項目）、番茄鐘圖片和音樂，含編碼媒體上限 32 MiB。超過時不會匯出不完整備份。WeatherAPI 金鑰、瀏覽器書籤與權限不包含在內。備份檔含私人內容，請自行妥善保存；本功能不會上傳。網址媒體僅保留連結。還原前會顯示取代範圍，首次變更前會在本機 myntRestoreJournalV1 保存復原快照與進度；中斷後下次開啟會先回復，再重新載入開放操作。一般設定與媒體寫入於還原期間暫停；回復時比對預期版本並保留其他分頁的新內容。復原紀錄可能包含私人內容與媒體，僅存本機，不納入匯出；成功後移除。若瀏覽器可用空間不足以保存快照，會在變更資料前停止。

取消套用背景不刪圖庫檔案。自己加入的桌布經確認後會從本機 IndexedDB 永久刪除，無法復原並釋放空間；內建桌布隨擴充功能提供，刪除只會從圖庫與首頁移除，可在回收區復原。舊版或本機 MCP 移除的項目仍留在回收區並佔用本機空間，可逐張復原或永久刪除；顯示容量僅計算圖庫本機媒體和縮圖 Blob，不是瀏覽器整站儲存用量，也不包含遠端網址內容。書籤圖示只使用瀏覽器本機快取或內建替代圖示，不將書籤網域送往 Google 圖示服務。

Before restore changes any domain data, a local-only myntRestoreJournalV1 journal saves rollback snapshots and write-ahead progress. Interrupted restores are undone on next startup before ordinary operations resume. Normal settings/media writers are paused across tabs, and recovery preserves concurrently changed content instead of overwriting it. The journal may contain private content and media, is excluded from exports, and is removed after successful restore/recovery. Insufficient snapshot storage stops restore before domain changes.

Local event countdowns / 本機重要日期倒數

Exam, anniversary and custom event names, calendar dates, display preferences and the latest recoverable deletion are stored only in this browser under myntEventCountdownsV1. Both settings-only and full backups include these events. No dates are sent to a server; exam dates are user-defined, not verified official schedules. Annual dates use the Gregorian calendar and observe February 29 on February 28 in non-leap years. / 特考、紀念日及自訂日期僅存於本機，兩種備份均包含；不自動查詢官方考期，不上傳資料。每年重複使用公曆，非閏年以 2 月 28 日計算 2 月 29 日事件。

Recoverable task and shortcut deletions / 待辦與捷徑刪除復原

Recoverable deletions made through local MCP keep one task in myntTodoRecoveryV1 and one shortcut in myntShortcutRecoveryV1 in localStorage. A task retains its identifier, title, completion and pin status and original position; a shortcut retains its name, URL, custom icon and original position. These are not permanent deletions. A further MCP deletion in the same list is refused until the retained item is restored. Undo is available in the ordinary task panel or shortcut editor without connecting MCP, survives page reload, and removes the recovery entry only after a successful restore. Clearing browser data or uninstalling the extension can remove this recovery data.

本機 MCP 的可復原刪除會在 localStorage 的 myntTodoRecoveryV1 保留一筆待辦，在 myntShortcutRecoveryV1 保留一筆捷徑。待辦保留識別碼、標題、完成／釘選狀態及原位置；捷徑保留名稱、網址、自訂圖示及原位置，並非永久刪除。同一清單尚有復原項目時，不接受下一次 MCP 刪除。重新載入後仍可直接在一般待辦面板或捷徑編輯器復原，不必連接 MCP；成功後才移除復原紀錄。清除瀏覽器資料或解除安裝可能刪除復原資料。

Both local backup scopes include validated recovery records and custom shortcut icons, as with the existing shortcut settings. Settings-only export does not open wallpaper, gallery, timer-image or music databases. Backup files can therefore contain private task text, full shortcut URLs and retained icons; keep them private. Recovery records are validated before export or restore, and malformed records are not applied. MCP shortcut responses omit icon data and redact credentials, queries and fragments from URLs. Recovery adds no telemetry, network service, permission or automatic upload.

兩種本機備份都包含驗證通過的復原紀錄與自訂捷徑圖示，與既有捷徑設定相同。「僅設定」不會開啟桌布、圖庫、計時器圖片或音樂資料庫。備份可能包含私人待辦文字、完整捷徑網址及保留的圖示，請妥善保管。匯出或還原前會驗證復原紀錄，不會套用格式錯誤的資料。MCP 的捷徑回覆不包含圖示原始資料，網址也會隱去帳密、查詢參數及片段。此功能不新增遙測、網路服務、權限或自動上傳。

Music recovery / 音樂復原

Removed music tracks remain in the existing local myntPomodoroMusicV1/tracks store with their audio file and a removedAt timestamp. They stay out of active playback and can be restored from the music panel without automatically starting playback. Retained tracks still count toward the 30-track and 300 MiB library limits. Full backups preserve retained tracks and timestamps within the separate 32 MiB encoded backup limit; settings-only backups never read or include this music database. Original device files are not changed or uploaded. These recovery features add no permissions, remote services or telemetry.

已移除曲目的音訊檔及 removedAt 時間戳記會保留在既有本機 myntPomodoroMusicV1/tracks 儲存區，不參與播放，可在音樂面板還原，且不會自動開始播放。保留曲目仍計入 30 首及 300 MiB 音樂庫上限。「設定＋媒體」備份保留這些曲目與時間戳記，但仍受含編碼資料 32 MiB 的備份上限限制；「僅設定」不會讀取或包含音樂資料庫。不會更動或上傳裝置上的原始檔案，也不新增權限、遠端服務或遙測。

Optional local MCP / 可選本機 MCP

The MCP bridge is off by default. Chromium and Firefox declare nativeMessaging only as an optional permission: clicking Connect requests browser approval before any native connection. Denial leaves the bridge disconnected. Separate, explicitly approved native host registration is still required. A manually connected session exposes only documented domain tools to local AI clients, not arbitrary scripts, filesystem access, credentials or raw media. Read/write and bookmark access are separately selected for each session and are not included in backups. Your chosen AI client may transmit tool results to its model provider. Disconnect or close the page to revoke this session. Local IPC is not an authorization boundary against other malicious software already running as your OS user.

本機 MCP 預設關閉。Chromium 與 Firefox 僅宣告選用 nativeMessaging 權限；點選連線時才要求瀏覽器授權，拒絕時維持中斷連線。仍須另行明確核准原生主機註冊，並手動連接。每次連線分別選擇修改及私人內容讀取；關閉分頁或中斷即撤回，不納入備份。不提供任意程式、檔案系統、憑證或媒體原始檔。請注意 AI 用戶端可能把工具結果傳送給其模型供應商，同一作業系統帳號的惡意程式不在本機 IPC 的安全隔離範圍內。

Component visibility / 元件顯示

Component management uses existing local visibility preferences (including showShortcutSwitch for the search provider row), plus myntSearchVisible, myntGalleryEntryVisible, myntProfilesEntryVisible and myntAdaptiveEntryVisible for optional entry points, and myntServiceStatusPillVisible for the homepage service status alert. Hiding that alert does not stop or delete the local service status record shown in the Control Center. The homepage Today widgets visibility preference (myntHomeWidgetsVisible) is stored only locally. Hiding preserves content and saved layout positions. A one-time myntComponentsMigrationV1 marker preserves previously CSS-hidden defaults only when the old preference was absent, recording only null preimages. Explicit choices are never rewritten. Both backup scopes include these preferences and migration marker. No new network service, permission or upload is added.

元件管理沿用既有本機顯示設定（搜尋服務列沿用 showShortcutSwitch），另保存搜尋列、桌布圖庫、排版設定檔、自動外觀入口及首頁服務狀態提示（myntServiceStatusPillVisible）的顯示偏好；隱藏提示不會停止或刪除控制中心使用的本機服務狀態紀錄，以及首頁今日小工具顯示偏好（myntHomeWidgetsVisible，只存在本機）。隱藏不刪除內容及已儲存位置。myntComponentsMigrationV1 只在舊顯示偏好缺值時，記錄一次相容處理及空值原貌，不覆蓋明確設定；兩種備份皆包含這些設定；不新增連線服務、權限或上傳。

Encouragement lines / 鼓勵語

Encouragement lines you add, paste or import (text, optional author and source, up to five tags, whether each is shown), the built-in lines you hide and the categories chosen for the homepage are stored locally in myntStudyQuotesV1. The rotation that avoids repeats is kept in myntQuoteBag and records only quote identifiers. Imported files are read in the browser and treated as plain text; exports are created on this device and downloaded only when you choose Export. Both backup scopes include these lines, and a restore validates them before writing. No network service, permission, telemetry or upload is added.

你自行新增、貼上或匯入的鼓勵語（內容、選填的作者與出處、最多五個標籤、是否顯示）、你隱藏的內建語錄，以及首頁要顯示的分類，都只保存在本機 myntStudyQuotesV1。避免重複的輪播順序保存在 myntQuoteBag，只記錄句子識別碼。匯入的檔案只在瀏覽器內讀取並一律當作純文字；匯出檔在本機產生，只有在你按下「匯出」時才下載。兩種備份皆包含這些內容，還原前會先驗證。不新增網路服務、權限、遙測或上傳。

Quick-link icons / 快捷連結圖示

Shortcut icons remain string values in shortcutIcon<N>. AI tool name, website URL and icon overrides are stored locally in aiToolsCustom, alongside aiToolsSettings for visibility and order. AI tools you add yourself (name, website URL, optional icon, visibility and position) are stored locally in aiToolsUserTools; deleting one removes it from that record. Deleting a built-in AI tool keeps it hidden in aiToolsSettings and lists its identifier in aiToolsUserTools until you add it back or reset. Their automatic icon is the first letter of the name, or the browser favicon only when the existing optional favicon permission is already granted, so adding a tool makes no network request. Both backup scopes include these settings and icon data. The bundled icon library, emoji and text badges run locally. Automatic website icons use the browser favicon endpoint only when its existing optional favicon permission is granted; otherwise shortcuts retain their existing preset / favicon behaviour, which uses Google's favicon service by default; turning off "Website icons from Google" under Settings > Shortcuts (stored locally as googleFaviconToggle and included in both backup scopes) stops those requests and shows the bundled or first-letter icon instead. Custom image URLs are loaded only as images. No new service, permission, telemetry or automatic upload is added.

捷徑圖示沿用 shortcutIcon<N> 字串；AI 工具名稱、網址與圖示的客製值保存在本機 aiToolsCustom，顯示與順序沿用 aiToolsSettings；自行新增的 AI 工具（名稱、網址、選用圖示、顯示狀態與位置）保存在本機 aiToolsUserTools，刪除即從該紀錄移除；刪除內建 AI 工具時，該工具在 aiToolsSettings 中保持隱藏，並在 aiToolsUserTools 記下其識別碼，直到加回或重設。其自動圖示使用名稱首字，只有在既有選用 favicon 權限已授予時才使用瀏覽器圖示，新增工具不會發出網路請求。兩種備份皆包含這些資料與圖示。內建圖示庫、Emoji 與文字圖示均在本機處理；自動網站圖示只在既有選用 favicon 權限已授予時使用瀏覽器端點，否則沿用捷徑原有圖示行為（預設使用 Google 圖示服務；在「設定 > 捷徑」關閉「從 Google 取得網站圖示」後即不再發出這些請求，改用內建或首字圖示；此設定以 googleFaviconToggle 保存在本機，兩種備份皆包含）。自訂圖片網址僅作為圖片載入；不新增服務、權限、遙測或自動上傳。

Theme colours / 主題色

The selected palette (selectedTheme) or custom colour (customThemeColor), up to six recent custom colours (myntRecentThemeColors) and optional light-mode colours for the page background, side panels, cards and text (myntThemeSurfaces, version 1) are stored only in localStorage. A palette saved by an earlier version is converted once to the closest current palette. Colours are checked as hex values whenever they are read. No network service, permission, telemetry or upload is added.

選取的主題色（selectedTheme）或自訂顏色（customThemeColor）、最多六個最近使用的自訂顏色（myntRecentThemeColors），以及淺色模式下頁面背景、側欄、卡片與文字的分區顏色（myntThemeSurfaces，版本 1）只保存在 localStorage。舊版儲存的主題色會在第一次開啟時轉換成最接近的新主題色；每次讀取都會驗證色碼格式。不新增網路服務、權限、遙測或上傳。

Web version / 網頁版

These items exist only on the website (for example on a tablet), not in the browser extension. The site can be installed as an app: the browser reads a local web app manifest and bundled icons from the same site, and nothing is sent elsewhere. A one-time install card remembers that you closed it in localStorage (myntWebInstallHintDismissed). When the site runs as an installed app, it asks the browser once to keep its storage under storage pressure (navigator.storage.persist) and records that request in myntWebStoragePersistRequested; the browser may decline. On iPhone and iPad, an app added to the Home Screen keeps its data separately from the browser, so settings made in a browser tab do not appear in it; use Backup and Restore to move them. A status badge for checking the site uses localStorage (myntWebPreviewBadgeCollapsed for its collapsed state and myntPreviewLastSnapshot for the latest page-health summary: page address, title, language, version, branch and commit, shortcut and settings-entry counts, and error messages) and sessionStorage (myntPreviewRuntimeErrors, the latest page errors in this tab). The badge is shown only when a problem is found or the address ends with ?preview. These records stay on this device and are not uploaded. No account, tracking, telemetry or new permission is added.

以下項目只存在網頁版（例如平板），擴充功能沒有。網頁版可安裝成 App：瀏覽器只讀取同一網站內的 Web App 設定檔與內建圖示，不會傳送任何資料到其他地方。一次性的安裝提示卡會在 localStorage 記住你已關閉（myntWebInstallHintDismissed）。以已安裝 App 開啟時，會向瀏覽器要求一次在儲存空間不足時保留資料（navigator.storage.persist），並在 myntWebStoragePersistRequested 記下已要求；瀏覽器可能拒絕。iPhone 與 iPad 上，加入主畫面的 App 和瀏覽器的資料是分開的，在瀏覽器分頁做的設定不會出現在主畫面 App 裡，可用「備份」與「還原」搬過去。檢查網站狀態用的狀態條使用 localStorage（myntWebPreviewBadgeCollapsed 記錄收合狀態；myntPreviewLastSnapshot 記錄最近一次頁面健康摘要：頁面網址、標題、語言、版本、分支與 commit、捷徑與設定項目數量及錯誤訊息）與 sessionStorage（myntPreviewRuntimeErrors，本分頁最近的頁面錯誤）。狀態條只在偵測到問題或網址加上 ?preview 時顯示。這些紀錄只留在本機、不會上傳；不新增帳號、追蹤、遙測或權限。
