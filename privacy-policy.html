MYNT: Material You New Tab 隱私權政策

最後更新：2026 年 10 月 24 日

簡介

「MYNT: Material You New Tab」是一款開源擴充功能，旨在美化瀏覽器的預設首頁和新分頁。它最初是使用 HTML、CSS 和 JavaScript 開發的個人專案。由於獲得正面評價，後來在 Firefox 和 Chrome 線上應用程式商店上架。

社群貢獻

自發布以來，社群中優秀的開發者透過 GitHub 為改善此擴充功能做出了貢獻。這些貢獻者新增了新功能並修復了錯誤，使擴充功能更加完善。每個 Pull Request 都經過仔細審查、測試和驗證，確保符合我們的標準後才會合併。

番茄鐘小窗與本機媒體

番茄鐘的 pomodoroState（版本 2）在 localStorage 保存結束時間、暫停狀態、任務與回合。分頁使用本機鎖協調完成提示，沒有新增帳號、網路服務或瀏覽器權限；關閉瀏覽器或休眠不保證準時提醒。小窗僅由按鈕開啟，一般彈出視窗不保證置頂。

myntPomoScenarios、myntPomoStudioMode、myntPomoAlarmVolume 保存情境、介面與提示音偏好。myntPomodoroAppearance.v1 保存獨立背景設定；IndexedDB MyntPomodoroAppearance 的 images 保存一張最多 8 MiB 本機圖片。myntPomodoroMusicV1 的 tracks 保存自選音樂，最多 30 首、每首 100 MiB、合計 300 MiB；myntPomoMusicSettingsV1 保存播放順序、音量與休息政策，myntPomoMusicOwnerV1 僅用於暫時跨分頁播放協調。媒體不會上傳伺服器；第 3 版本機備份可選「設定＋媒體」或「僅設定」（含編碼資料上限 32 MiB），舊版備份不含完整媒體庫；移除擴充功能或清除網站資料可能刪除。情境只保存媒體識別與偏好，不複製音樂檔。

Timer, scenarios, images and music remain browser-local. No media is uploaded. Version 3 local backups offer settings plus media or settings-only exports within a 32 MiB encoded-file limit; older backups do not contain complete media libraries. Browser shutdown, sleep and autoplay restrictions can prevent timely alarms or playback. Floating windows require the original tab; ordinary popup windows are not guaranteed to remain on top.

背景自適應與排版儲存

myntLayoutProfiles（版本 1）只在本機保存命名組合、寬／窄螢幕位置、上一個儲存版本與修訂號。舊 myntLayout 保留，不刪除；排版專用 JSON 匯出不含便籤、帳號或 API 金鑰，匯入先驗證並確認後新增副本。不同分頁的過期寫入會拒絕，以免覆寫更新。

Named layout profiles and previous versions stay in localStorage. Layout-only exports contain no notes, accounts or API keys; validated imports add copies after confirmation.

背景圖片與影片像素只在本機 Canvas 進行低解析度色彩、亮度與紋理分析，不傳送到模型或伺服器。localStorage 的 myntAdaptiveBackground（版本 1）保存背景／手動主色、柔和／鮮明強度、對比與透明度偏好，沿用舊配色開關表示來源，不新增個人資料，舊自動排版設定固定轉為關閉；myntLayout（版本 2）保存手動相對位置、縮放、格線與鎖定。背景功能不會移動元件，也不覆寫手動位置。這些設定不跨裝置同步，清除網站資料會刪除設定。無新增權限、網路服務或遙測。

Adaptive background processing stays on-device. Versioned local preferences are stored in myntAdaptiveBackground and myntLayout. No pixels are uploaded and no new remote service is used.

資料收集與權限

MYNT 不包含由專案營運的分析工具、追蹤腳本、遙測或遠端記錄系統。偏好設定、待辦事項、快取資料與客製內容主要儲存在您的瀏覽器內；但啟用搜尋建議、天氣、語音辨識、隨機桌布、語錄或網站圖示等功能時，瀏覽器會直接連線至下列第三方服務。第三方至少會看到一般網路請求中包含的 IP 位址，並可能收到查詢字詞、位置或網站網域。

權限

我們僅要求提供豐富、動態瀏覽體驗所需的最低權限。以下是所使用權限的說明：

  • 書籤：只在您啟用書籤功能後請求。此權限可讀取、新增、修改與刪除瀏覽器書籤。
  • 網站圖示（Chrome 選用）：用於從瀏覽器快取讀取書籤圖示。若快取沒有圖示，書籤會改用內建替代圖示，不傳送書籤網域。
  • Google 網域（選用）：只在您啟用 Google 搜尋建議後請求。
  • 擴充功能儲存空間：在瀏覽器的 extension storage 中保存呆呆的受限本機配對權杖與已處理操作 ID；不會保存呆呆主權杖。
  • 本機呆呆橋接（選用）：只有按下「連接呆呆」後，才請求連線至 http://127.0.0.1/*。此位址只代表目前電腦，不會連到區域網路或專案營運者的伺服器。

瀏覽器 API

  • 語音辨識（Web Speech API）：僅在您點擊麥克風圖示後啟動。音訊處理由瀏覽器提供者控制，依瀏覽器實作可能傳送至其語音服務；MYNT 不另行儲存音訊。
  • 地理位置：僅在您確認啟用 GPS 天氣後請求。取得的經緯度會傳送至 WeatherAPI 以查詢天氣。

呆呆連動（選用）

呆呆連動預設未配對。配對時，呆呆會顯示一次性 6 位數配對碼；成功後 MYNT 只取得無法存取一般呆呆橋接 API 的受限權杖。解除連動會撤銷該權杖並移除本機主機權限。

連動後，MYNT 會將今日待辦的標題與完成狀態、今日專注分鐘／階段／連續天數，以及習慣名稱與今日狀態送至本機呆呆橋接。便籤全文不會自動分享；只有按下「問呆呆」或「呆呆整理待辦」時，才會送出目前選取文字或游標所在行。書籤、捷徑網址、搜尋紀錄與首頁稱呼不會透過此連動分享。

只有在您向呆呆提出 MYNT、待辦、便籤、專注、習慣或今日工作相關要求時，相關摘要或您主動送出的便籤文字才會隨該次訊息交給呆呆目前設定的 AI 後端／模型供應商處理。資料處理由該供應商的政策約束；MYNT 專案本身不接收副本。

呆呆提出的新增、修改、完成待辦或便籤操作只會排入本機預覽。您在 MYNT 明確按下「確認套用」前不會寫入；拒絕、過期、資料版本不符或關閉配對時都不會套用。

外部 API

只有相關功能啟用或觸發時，MYNT 才會使用下列服務：

  • 搜尋建議：
    • Google：https://www.google.com/complete/search?client=*

    搜尋建議預設關閉。啟用後，輸入的查詢字詞會直接傳送至 Google；若同時啟用代理，查詢會先傳送至您設定的代理伺服器。

  • 位置偵測（IPinfo）：
    • https://ipinfo.io/json — 天氣功能開啟且未設定手動位置或 GPS 時，根據 IP 位址取得約略經緯度。

    只有在天氣元件實際顯示且未被停用時，才會連線至 IPinfo，接著向 WeatherAPI 查詢天氣。若版面未呈現天氣元件或您在設定中隱藏天氣，MYNT 不會為不可見的天氣內容發出位置或天氣請求。

  • 天氣更新（WeatherAPI）：
    • https://api.weatherapi.com/v1/forecast.json?key=* — 接收手動位置、IP 推估位置或 GPS 經緯度，以及語言偏好。
    • https://api.weatherapi.com/v1/search.json?key=* — 使用自訂 API 金鑰時，接收您輸入的城市查詢以提供位置建議。

    專案內含可公開檢視的共用 WeatherAPI 金鑰，也允許您輸入自己的金鑰。自訂金鑰會以純文字儲存在瀏覽器的 localStorage，並作為 HTTPS 查詢參數傳送。備份檔會刻意排除自訂 API 金鑰，還原後如有需要請重新輸入。請勿把同一組金鑰用於其他敏感用途。

  • 隨機桌布（Lorem Picsum）：
    • https://picsum.photos/1920/1080 — 用於取得高品質隨機圖片。
  • 語錄（多語言語錄 API）：
    • https://prem-k-r.github.io/multilingual-quotes-api/ — 語錄功能啟用時下載語系中繼資料與語錄內容。
  • 網站圖示擷取（Google Favicon API）：
    • https://s2.googleusercontent.com/s2/favicons*
    • https://www.google.com/s2/favicons*
    這些服務會收到捷徑的網站網域，用於擷取捷徑圖示；書籤改用瀏覽器本機快取或內建替代圖示。

考古題與主動開啟 ChatGPT

「今日考古題」預設顯示，啟用時會在閒置後從 raw.githubusercontent.com 的 Reese-max/police-exam-archive 公開題庫下載並快取當日題目。GitHub 會收到一般網路請求資訊（例如 IP），請求不含待辦、便籤或書籤。可在設定停用此卡片，停止後續自動題庫請求。

只有按下每日焦點的「問 GPT 拆解步驟」時，才會透過 chatgpt.com/?q= 開啟已填入的提示，包含目前焦點文字、選擇的科目及距考試天數。這些內容會傳至 OpenAI，並可能留在瀏覽器歷史；請勿填入不想分享的私人資料。MYNT 不會自動替您送出聊天訊息。

本機儲存

MYNT 使用 localStorage 與 IndexedDB 儲存介面設定、首頁稱呼、每日焦點文字／完成狀態／延續日期、待辦事項、書籤顯示偏好、自訂捷徑圖示、天氣位置與快取、語錄快取與每日語錄、番茄鐘狀態、專注紀錄、便籤、每日習慣、工作區預設、無障礙偏好及上傳的桌布。首頁稱呼只會顯示在本機問候語中；每日焦點也不會自動分享給呆呆。兩者都會包含在您主動匯出的 MYNT 備份檔。呆呆受限配對權杖與最近已確認／拒絕的操作 ID 存在 extension storage，不會進入 MYNT 一般備份檔；重設 MYNT 或解除連動時會清除。移除擴充功能或清除網站資料時，瀏覽器可能一併刪除這些內容。

控制中心的服務狀態只會在 localStorage 記錄服務識別名稱、成功或失敗結果、HTTP 狀態碼及時間；不會記錄完整網址、搜尋文字、位置、API 金鑰，也不會傳送至專案營運者。

代理伺服器（選用）

MYNT: Material You New Tab 包含一項選用的代理功能，預設為停用。此功能可用於在取得搜尋建議時繞過 CORS 限制。

對於希望啟用此功能的使用者，我們強烈建議自行架設代理伺服器，以保持完全控制並確保最大程度的隱私保護。

如果啟用並保持預設設定，搜尋建議請求將透過以下公共代理轉發：https://mynt-proxy.rhythmcorehq.com。代理營運者會看到您的 IP 位址與完整搜尋建議請求。

更新與解除安裝頁面

Chromium 版本更新後會在本機開啟擴充功能內的 docs/whats-new.html，說明本次整合內容。解除安裝後，瀏覽器可能開啟 Reese-max Fork 的公開 GitHub 頁面供您自行查看；此動作不會自動上傳擴充功能設定、便籤、待辦、搜尋文字、位置、API 金鑰或其他本機資料。

透明度與安全性

雖然我們努力保持程式碼的安全性，但我們承認沒有任何專案能完全避免潛在問題。在少數情況下，可能會因貢獻而引入非預期的程式碼或錯誤。我們鼓勵使用者直接在 GitHub 上檢閱原始碼以確保安心。請僅在您完全信任其內容時使用此擴充功能。

感謝

感謝您對 MYNT: Material You New Tab 擴充功能的信任。我們希望它能在您每次開啟新分頁時提升您的瀏覽體驗！

Layout draft recovery uses sessionStorage (myntLayoutDraft) only in the current tab and survives reload, not guaranteed tab closure. The dismissible guide preference uses localStorage (myntLayoutGuideSeen). Deleted layout profiles remain recoverable locally; no data is uploaded.

Permanent deletion is available only for individual custom items already in Recovery, after an explicit irreversible confirmation. It deletes that gallery record and thumbnail, and any legacy cache explicitly owned by that record. Unowned legacy caches, other features’ separately saved copies, device originals and exported backups are not erased. New cached gallery images carry a local ownership marker (myntGalleryCacheOwnerV1); full backup restoration discards this ephemeral marker rather than guessing ownership. 本機圖庫永久刪除須先移至回收區，再逐張明確確認；不影響其他功能另存副本、來源檔或已匯出備份。未知來源的舊快取保留，不假設其擁有者。

Wallpaper gallery removal is recoverable: removed custom images and videos stay in this browser’s local IndexedDB so Undo remains available after reload. They are excluded from gallery playback but still use local storage. Original files on your device are not modified or uploaded.

「僅設定」可匯出一般設定、排版、待辦、便籤及還原後暫停的計時狀態，不讀取或包含媒體資料庫，也不包含桌布偏好、計時器外觀、音樂偏好與已儲存專注情境。還原時保留目的端的這些媒體及偏好；舊版 v1／v2 備份同樣保留未涵蓋的媒體關聯偏好。完整備份不會自動降級為僅設定；音樂庫可達 300 MiB，不代表能放入 32 MiB 備份，請另行保留原始媒體檔。

Settings-only exports omit media databases and media-linked wallpaper, timer appearance, music and saved scenario preferences. Restoring them preserves those existing destination files and preferences. Legacy v1/v2 restores likewise preserve omitted media-linked preferences. Full exports never silently downgrade; retain original media separately when the 32 MiB encoded backup limit is exceeded.

本機備份第 3 版的「設定＋媒體」包含設定、排版、待辦、便籤、圖庫（含回收項目）、番茄鐘圖片和音樂，含編碼媒體上限 32 MiB。超過時不會匯出不完整備份。WeatherAPI 金鑰、瀏覽器書籤與權限、DaiDai 配對不包含在內。備份檔含私人內容，請自行妥善保存；本功能不會上傳。網址媒體僅保留連結。還原前會顯示取代範圍，已知寫入失敗會嘗試恢復原資料，但不能保證關閉分頁或系統中斷時跨資料庫原子性。

取消套用背景不刪圖庫檔案。回收區可逐張復原；顯示容量僅計算圖庫本機媒體和縮圖 Blob，不是瀏覽器整站儲存用量，也不包含遠端網址內容。書籤圖示只使用瀏覽器本機快取或內建替代圖示，不將書籤網域送往 Google 圖示服務。

Local event countdowns / 本機重要日期倒數

Exam, anniversary and custom event names, calendar dates, display preferences and the latest recoverable deletion are stored only in this browser under myntEventCountdownsV1. Both settings-only and full backups include these events. No dates are sent to a server; exam dates are user-defined, not verified official schedules. Annual dates use the Gregorian calendar and observe February 29 on February 28 in non-leap years. / 特考、紀念日及自訂日期僅存於本機，兩種備份均包含；不自動查詢官方考期，不上傳資料。每年重複使用公曆，非閏年以 2 月 28 日計算 2 月 29 日事件。

Recoverable task and shortcut deletions / 待辦與捷徑刪除復原

Recoverable deletions made through local MCP keep one task in myntTodoRecoveryV1 and one shortcut in myntShortcutRecoveryV1 in localStorage. A task retains its identifier, title, completion and pin status and original position; a shortcut retains its name, URL, custom icon and original position. These are not permanent deletions. A further MCP deletion in the same list is refused until the retained item is restored. Undo is available in the ordinary task panel or shortcut editor without connecting MCP, survives page reload, and removes the recovery entry only after a successful restore. Clearing browser data or uninstalling the extension can remove this recovery data.

本機 MCP 的可復原刪除會在 localStorage 的 myntTodoRecoveryV1 保留一筆待辦，在 myntShortcutRecoveryV1 保留一筆捷徑。待辦保留識別碼、標題、完成／釘選狀態及原位置；捷徑保留名稱、網址、自訂圖示及原位置，並非永久刪除。同一清單尚有復原項目時，不接受下一次 MCP 刪除。重新載入後仍可直接在一般待辦面板或捷徑編輯器復原，不必連接 MCP；成功後才移除復原紀錄。清除瀏覽器資料或解除安裝可能刪除復原資料。

Both local backup scopes include validated recovery records and custom shortcut icons, as with the existing shortcut settings. Settings-only export does not open wallpaper, gallery, timer-image or music databases. Backup files can therefore contain private task text, full shortcut URLs and retained icons; keep them private. Recovery records are validated before export or restore, and malformed records are not applied. MCP shortcut responses omit icon data and redact credentials, queries and fragments from URLs. Recovery adds no telemetry, network service, permission or automatic upload.

兩種本機備份都包含驗證通過的復原紀錄與自訂捷徑圖示，與既有捷徑設定相同。「僅設定」不會開啟桌布、圖庫、計時器圖片或音樂資料庫。備份可能包含私人待辦文字、完整捷徑網址及保留的圖示，請妥善保管。匯出或還原前會驗證復原紀錄，不會套用格式錯誤的資料。MCP 的捷徑回覆不包含圖示原始資料，網址也會隱去帳密、查詢參數及片段。此功能不新增遙測、網路服務、權限或自動上傳。

Habit and music recovery / 習慣與音樂復原

Local MCP can recoverably remove a custom habit, never a built-in automatic habit. myntHabitRecoveryV1 retains one custom habit with its identifier, name, original list position and completion-date history. Another removal is refused until it is restored. Undo in the ordinary habits panel works without connecting MCP; duplicate identifiers or names and a full 12-habit list block restoration without discarding the retained item. Both local backup scopes include validated habit recovery data. Malformed habit or recovery records are preserved rather than silently reset.

本機 MCP 可復原地移除自訂習慣，但不能移除內建自動習慣。myntHabitRecoveryV1 保留一筆自訂習慣的識別碼、名稱、原清單位置與完成日期紀錄，復原前不接受下一次移除。不必連接 MCP，即可在一般習慣面板復原；識別碼或名稱重複、或已達 12 個自訂習慣上限時，會停止復原並保留紀錄。兩種本機備份都包含驗證通過的習慣復原資料。格式錯誤的習慣或復原紀錄會保留，不會默默重設。

Removed music tracks remain in the existing local myntPomodoroMusicV1/tracks store with their audio file and a removedAt timestamp. They stay out of active playback and can be restored from the music panel without automatically starting playback. Retained tracks still count toward the 30-track and 300 MiB library limits. Full backups preserve retained tracks and timestamps within the separate 32 MiB encoded backup limit; settings-only backups never read or include this music database. Original device files are not changed or uploaded. These recovery features add no permissions, remote services or telemetry.

已移除曲目的音訊檔及 removedAt 時間戳記會保留在既有本機 myntPomodoroMusicV1/tracks 儲存區，不參與播放，可在音樂面板還原，且不會自動開始播放。保留曲目仍計入 30 首及 300 MiB 音樂庫上限。「設定＋媒體」備份保留這些曲目與時間戳記，但仍受含編碼資料 32 MiB 的備份上限限制；「僅設定」不會讀取或包含音樂資料庫。不會更動或上傳裝置上的原始檔案，也不新增權限、遠端服務或遙測。

Optional local MCP / 可選本機 MCP

The MCP bridge is off by default and is not granted native messaging permission in this build. Separate host registration and permission approval are required. A manually connected session exposes only documented domain tools to local AI clients, not arbitrary scripts, filesystem access, credentials or raw media. Read/write and scratchpad/bookmark access are separately selected for each session and are not included in backups. Your chosen AI client may transmit tool results to its model provider. Disconnect or close the page to revoke this session. Local IPC is not an authorization boundary against other malicious software already running as your OS user.

本機 MCP 預設關閉，本版未啟用原生通訊權限。須另行核准主機註冊與權限，並手動連接。每次連線分別選擇修改及私人內容讀取；關閉分頁或中斷即撤回，不納入備份。不提供任意程式、檔案系統、憑證或媒體原始檔。請注意 AI 用戶端可能把工具結果傳送給其模型供應商，同一作業系統帳號的惡意程式不在本機 IPC 的安全隔離範圍內。

Component visibility / 元件顯示

Component management uses existing local visibility preferences, plus myntSearchVisible, myntGalleryEntryVisible, myntProfilesEntryVisible and myntAdaptiveEntryVisible for optional entry points. Hiding preserves content and saved layout positions. A one-time myntComponentsMigrationV1 marker preserves previously CSS-hidden defaults only when the old preference was absent, recording only null preimages. Explicit choices are never rewritten. Both backup scopes include these preferences and migration marker. No new network service, permission or upload is added.

元件管理沿用既有本機顯示設定，另保存搜尋列、桌布圖庫、排版設定檔與自動外觀入口的顯示偏好。隱藏不刪除內容及已儲存位置。myntComponentsMigrationV1 只在舊顯示偏好缺值時，記錄一次相容處理及空值原貌，不覆蓋明確設定；兩種備份皆包含這些設定；不新增連線服務、權限或上傳。
